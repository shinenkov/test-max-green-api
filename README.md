# MAX Chat - тестовое задание

Веб-интерфейс для обмена текстовыми сообщениями в мессенджере **MAX** через сервис [GREEN-API](https://green-api.com/max).

Прототип интерфейса - [web.max.ru](https://web.max.ru/).

---

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Переименовать .env.example в .env и заполнить apiUrl
cp .env.example .env

# 3. Запустить дев-сервер
npm run dev
```

После запуска откройте [http://localhost:3001](http://localhost:3001).

### Переменные окружения

В файле `.env` укажите URL вашего инстанса GREEN-API:

```env
VITE_GREEN_API=https://3100.api.green-api.com
```

Хост зависит от вашего инстанса - посмотрите его в [личном кабинете GREEN-API](https://console.green-api.com/).

---

## Задание

В рамках тестового задания требуется разработать пользовательский интерфейс для отправки и получения сообщений в MAX.

### Требования

1. Разработать пользовательский интерфейс для отправки и получения сообщений в MAX
2. Использовать сервис [GREEN-API](https://green-api.com/max)
3. Реализовать отправку и получение **только текстовых** сообщений
4. За прототип интерфейса взять внешний вид чата [web.max.ru](https://web.max.ru/)
5. Реализовать интерфейс максимально простым, с минимальным набором функций
6. Отправку сообщений реализовать методом [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/)
7. Получение сообщений реализовать методом [`ReceiveNotification`](https://green-api.com/v3/docs/api/receiving/technology-http-api/)
8. Использовать технологию **React**

### Ожидаемый результат

- Пользователь переходит на сайт чата и вводит свои учётные данные из системы GREEN-API (`idInstance`, `apiTokenInstance`)
- Пользователь вводит номер телефона получателя и создаёт новый чат
- Пользователь пишет текстовое сообщение и отправляет его получателю в MAX
- Получатель отвечает на сообщение в мессенджере MAX
- Пользователь видит ответ получателя в чате
